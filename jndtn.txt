Краткий отчёт по переносу Marketplace

Сделана отдельная serverless-версия приложения для Bitrix24 Marketplace. Она находится в папке `marketplace/` и собирается в zip без серверной части.

Актуальная проверочная сборка:
- архив: `Калькулятор счетов Marketplace v10-5.zip`;
- версия: `layout-20260810-7`;
- состав zip: `install.html`, `install.js`, `install.css`, `index.html`, `app.js`, `style.css`.

Что работает:
- финальный дизайн перенесён в Marketplace-версию;
- приложение устанавливается, установщик завершался с `ok: true`;
- журнал установки накопительный, с timestamp и 4-секундной паузой перед завершением;
- приложение появляется в левом меню;
- создаются пользовательские поля сделки;
- поля отображаются нормальными названиями;
- работает сохранение сопоставления;
- раздел `Расчёт оплаты счетов` и поля появляются в карточке сделки;
- работает ручной пересчёт по ID/ссылке сделки;
- расчёт идёт через Bitrix24 REST напрямую;
- даты выставления и сроки оплаты выводятся без времени;
- ФИО ответственного подтягивается через `user.get`;
- добавлен диагностический блок `stageLookup` для стадий.
- в блоке `Автопересчёт` есть выбор режима, окно 42/28/21/14/7/2 суток, прогресс, ручной массовый пересчёт всех сделок в выбранном окне и автоматический CSV-отчёт.
- при выборе `Постоянный` показывается окно заявки на серверную поддержку, если у портала нет серверного флага в `app.option`.

Что проверить:
- после загрузки `v10-5` стадия счёта должна подтянуться через `crm.status.list` по `SMART_INVOICE_STAGE_*`;
- если стадия всё ещё отображается как `DT31_2:N`, нужен блок `stageLookup` из журнала ручного пересчёта.

Ограничение:
- Marketplace-версия без сервера не может принимать push-события Bitrix24, поэтому постоянный автопересчёт возможен только в будущей OAuth/server-версии.
