# Deal-Invoice-Summary
Приложение для Bitrix24 авт. рассчитывает в карточке сделки ключевые финансовые показатели по счетам:  Сумма выставленных счетов — общая сумма всех счетов, привязанных к сделке.  Сумма оплаченных счетов — сколько уже оплачено.  Сумма неоплаченных счетов — сколько ещё ожидает оплаты.  Остаток оплаты — разница между суммой сделки и суммой опл.счетов.
