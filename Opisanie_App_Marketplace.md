# Описание приложения для Bitrix24 Marketplace

## Полное описание приложения

Deal Invoice Summary помогает контролировать оплату счетов прямо в сделках Bitrix24.

Приложение показывает в карточке сделки понятную финансовую сводку: сколько выставлено по счетам, сколько уже оплачено, какая сумма остается к оплате и какие счета еще требуют внимания. Менеджеру не нужно вручную сверять счета по разным разделам и пересчитывать остаток в таблицах.

Что умеет приложение:

- показывает все счета, связанные со сделкой;
- разделяет оплаченные и неоплаченные суммы;
- считает остаток оплаты по сделке;
- показывает ответственного, сумму, стадию и дату по каждому счету;
- помогает обновлять расчетные поля в сделке;
- позволяет пересчитать одну сделку вручную;
- поддерживает массовый пересчет сделок за выбранный период;
- формирует отчет, который удобно открыть в Excel;
- показывает статистику сделок за период: завершенные, ожидающие доплаты и сделки без счетов.

Приложение полезно отделам продаж, руководителям и финансовым специалистам, которым важно быстро видеть состояние оплат по сделкам. Оно снижает количество ручных проверок, помогает быстрее находить сделки с долгом и делает контроль оплат более прозрачным.

После настройки приложение работает внутри Bitrix24 и доступно из привычного интерфейса. Основные действия выполняются по кнопке, поэтому пользователь сам контролирует, когда обновить расчеты или скачать отчет.

## Процесс установки

Установку выполняет администратор Bitrix24 или сотрудник с правом установки приложений.

После установки откройте приложение из меню Bitrix24. На первом запуске администратор создает стандартные расчетные поля и проверяет сопоставление полей сделки.

Затем выберите нужную воронку и период для расчета. После сохранения настроек приложение готово к работе: откройте сделку, проверьте сводку по счетам и при необходимости запустите пересчет.

Обычные сотрудники смогут пользоваться готовой сводкой, пересчитывать доступные им сделки и скачивать отчет, если у них есть права на просмотр соответствующих сделок и счетов.
